Bras de Fer : politique de confidentialité

Dernière mise à jour : 15 novembre 2026. English version

En bref : vos données restent sur votre appareil, chiffrées. Marega Studio n'exploite aucun serveur pour cette application, n'affiche aucune publicité et n'utilise aucun traceur ni outil d'analyse.

1. Responsable

Marega Studio (Fodié Marega, en cours d'immatriculation). Contact : lufygate@gmail.com. Le studio ne reçoit pas vos données ; vous restez maître de leur stockage.

2. Données traitées sur votre appareil

  • Données de sport et de santé que vous saisissez : séances, exercices, charges, poids du corps, mensurations, progression.
  • Nutrition : aliments, repas, objectifs.
  • Réglages de l'application et, si vous l'activez, le verrouillage biométrique (la vérification est faite par le système de votre appareil ; l'application ne reçoit pas vos données biométriques).

Ces données sont enregistrées localement, dans une base de données chiffrée (SQLCipher). La clé de chiffrement est conservée dans le trousseau sécurisé de l'appareil (Keychain sur iOS, Keystore sur Android) et n'en sort pas. Les données de santé sont des données sensibles : elles ne sont traitées que pour faire fonctionner l'application pour vous, sur la base de votre consentement (art. 9.2.a RGPD), que vous exprimez en les saisissant, et vous pouvez les supprimer à tout moment.

3. Connexions réseau

  • Sauvegarde GitHub (facultative) : si vous la configurez, l'application envoie une sauvegarde de vos données vers votre propre dépôt GitHub privé, avec votre jeton d'accès, stocké dans le trousseau sécurisé. Elle refuse d'écrire dans un dépôt public. Ce transfert est soumis à la politique de confidentialité de GitHub (hébergement notamment aux États-Unis). Le studio n'a accès ni à votre jeton ni à votre dépôt. Sans configuration, aucun envoi n'a lieu.
  • Recherche d'aliments par code-barres : lorsque vous scannez un produit, le code-barres est envoyé à la base ouverte Open Food Facts pour obtenir les informations nutritionnelles. Aucune autre donnée personnelle n'est envoyée, mais votre adresse IP est visible de ce service.

4. Autorisations

  • Appareil photo : uniquement pour scanner un code-barres. Les images ne sont pas conservées ni transmises.
  • Notifications : rappels que vous activez.
  • Aucune autorisation de position, de contacts ni de micro (le micro est explicitement bloqué).

5. Ce que nous ne faisons pas

Pas de publicité, pas de traceur, pas de cookie, pas d'analyse d'audience, pas de partage ni de vente de données, pas de compte chez nous.

6. Durée et suppression

Les données sont conservées sur votre appareil tant que vous ne les supprimez pas. Désinstaller l'application les efface. Une sauvegarde GitHub est sous votre contrôle : supprimez-la depuis votre dépôt.

7. Vos droits

Comme nous ne détenons pas vos données, vous exercez directement vos droits d'accès, de rectification, d'effacement et de portabilité dans l'application et dans votre dépôt. Pour toute question : lufygate@gmail.com (réponse sous un mois). Vous pouvez saisir la CNIL d'une réclamation.

8. Enfants

L'application n'est pas destinée aux enfants de moins de 13 ans.

9. Avertissement

Bras de Fer n'est pas un dispositif médical et ne remplace pas l'avis d'un professionnel de santé.
